# Titanic Survival Analysis 🚢

## Overview
A data analytics project analyzing survival patterns of Titanic passengers using Python.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Key Findings
1. Only 38% of passengers survived
2. Females had higher survival rates than males
3. 1st class passengers survived more than 3rd class
4. Cherbourg passengers had highest survival rate (55%)
5. Small families (2-4) survived better than solo travellers
6. Higher fare = better survival chances

## Model
Random Forest Classifier with 83.24% accuracy
